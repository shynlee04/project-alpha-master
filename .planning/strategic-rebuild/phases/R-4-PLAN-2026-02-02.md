### R-4-02: Archive src/lib/ to _archived/

**Description:** Move old code to archive, preserving for reference

**Commands:**
```bash
# Create archive directory with date
ARCHIVE_DATE=$(date +%Y-%m-%d)
mkdir -p _archived/lib-$ARCHIVE_DATE

# Move src/lib/ to archive
mv src/lib/* _archived/lib-$ARCHIVE_DATE/

# Remove empty src/lib/ directory
rmdir src/lib/

# Document what was archived
echo "# Archived: src/lib/" > _archived/lib-$ARCHIVE_DATE/README.md
echo "Date: $ARCHIVE_DATE" >> _archived/lib-$ARCHIVE_DATE/README.md
echo "Reason: Strategic Rebuild - replaced by src/platform/, src/modules/" >> _archived/lib-$ARCHIVE_DATE/README.md
echo "" >> _archived/lib-$ARCHIVE_DATE/README.md
echo "## Contents" >> _archived/lib-$ARCHIVE_DATE/README.md
echo "This archive contains the old lib/ directory that was replaced during the Strategic Rebuild." >> _archived/lib-$ARCHIVE_DATE/README.md
echo "It is preserved for reference but should NOT be used." >> _archived/lib-$ARCHIVE_DATE/README.md
```

**Verification:**
- src/lib/ no longer exists
- _archived/lib-YYYY-MM-DD/ contains old code
- README.md explains why archived

## Rollback Plan

If critical issues are discovered after cutover:

```yaml
rollback_plan:
  trigger:
    - Critical bug affecting all users
    - Data loss scenario
    - Security vulnerability
  
  steps:
    1. Stop deployment immediately
    2. Restore src/lib/ from _archived/
    3. Revert route changes to use old code
    4. Deploy previous working version
    5. Document issues for Phase R-4 retry
  
  commands:
    - mv _archived/lib-YYYY-MM-DD/* src/lib/
    - git checkout HEAD~1 -- src/routes/
    - pnpm deploy:rollback
```
