## Architecture Pattern: Strangler Fig

Instead of copying/rewriting the existing clean plugins, we created FACADES:

```
PlatformLayout
    │
    ├── FileTreeOperatorComponent (facade)
    │       └── fileTreePlugin.MainComponent (existing)
    │
    └── ChatOperatorView (facade)
            └── ChatPanel (existing)
```

Benefits:
- ✅ Preserves working code
- ✅ No duplication
- ✅ Clean interface for new architecture
- ✅ Easy to port incrementally later
