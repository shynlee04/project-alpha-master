## Strangler Fig Pattern

All modules use the Strangler Fig pattern:
- Clean module interface (`IFeatureModule`)
- Thin wrapper components (<60 lines each)
- Import from `@/plugins/*` NOT `@/lib/*`
- Lazy loading via `React.lazy()`

This allows:
1. Immediate feature parity
2. Clean interface for future refactoring
3. Gradual migration of internals

## Known Issue: Test Infrastructure

The 8 failing tests in `r3-notes-module.test.ts` are caused by:
1. Test attempts `await import('../notes')`
2. Notes module imports from `@/plugins/notes`
3. Plugin chain eventually imports route files
4. Route files use `createRootRoute` from TanStack Router
5. Test mock for `@tanstack/react-router` doesn't export `createRootRoute`

**Impact:** Test infrastructure only. Module code is correct.
**Resolution:** Fix TanStack Router mock in test setup OR isolate notes module tests.
