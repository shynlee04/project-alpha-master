# Technology Stack

**Project:** Project Alpha
**Researched:** 2026-01-31

## Recommended Stack

### Core Framework

| Technology | Version | Purpose | Why |
|------------|---------|---------|-----|
| TanStack Start | ^1.x | SSR-capable framework | Router-first, file-based routing, SSR support |
| TanStack Router | ^1.x | Client routing | Type-safe routes, loader pattern |
| React | ^18.x | UI library | Ecosystem, TanStack compatibility |
| TypeScript | ^5.x | Language | Type safety, required by TanStack |

### State Management

| Technology | Version | Purpose | Why |
|------------|---------|---------|-----|
| Zustand | ^5.x | Global state | Slices pattern, useShallow, minimal boilerplate |
| Dexie.js | ^4.x | IndexedDB wrapper | Live queries, migrations, TypeScript support |

**Key Patterns:**
- **useShallow** mandatory for all Zustand selectors (prevents re-renders)
- **NO persist middleware** on entity data (use Dexie for persistence)
- **Slices pattern** for stores >120 lines
- **Max 300 lines** per store file

### AI Integration

| Technology | Version | Purpose | Why |
|------------|---------|---------|-----|
| TanStack AI SDK | ^latest | AI client | Client-side tool calling, multi-provider |
| Orama | ^3.x | Vector search | Browser-native, TensorFlow.js embeddings |

**AI Provider Tier:**
1. **Tier 1 (Primary):** Gemini + OpenRouter (both OpenAI-compatible APIs)
2. **Tier 2 (Fallback):** Direct OpenAI, Anthropic

**Rationale:** Gemini offers competitive pricing and quality. OpenRouter provides access to multiple models through single API. Both use OpenAI-compatible endpoints, simplifying integration.

### Storage

| Technology | Version | Purpose | Platform |
|------------|---------|---------|----------|
| File System Access API | Browser native | Direct file access | Desktop only |
| IndexedDB (via Dexie) | Browser native | Structured storage | All platforms |
| OPFS | Browser native | Fallback file storage | Mobile/tablet |

**Platform Detection:**
```typescript
const hasFileSystemAccess = 'showDirectoryPicker' in window;
const platform = hasFileSystemAccess ? 'desktop' : 'mobile';
```

## Alternatives Considered

| Category | Recommended | Alternative | Why Not |
|----------|-------------|-------------|---------|
| AI SDK | TanStack AI | Vercel AI SDK | Vercel ties to serverless, TanStack is client-first |
| State | Zustand v5 | Redux, Jotai | Redux too verbose, Jotai less ecosystem |
| DB | Dexie.js | raw IndexedDB | Dexie provides migrations, live queries |
| Vector | Orama | Pinecone, Chroma | Orama runs in browser, no server needed |
| Framework | TanStack Start | Next.js | TanStack is router-first, better for SPA |
