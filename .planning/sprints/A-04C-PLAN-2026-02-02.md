# Phase A-04C: Remove Hardcoded Models - API-First Only

## Problem Statement

**Root Cause:** `ProviderSettings.tsx` lines 191-195 check `hasHardcodedModels()` FIRST, bypassing API-loaded models entirely for 6 major providers (groq, mistral, chutes, gemini, openrouter, openai).

**Impact:** Model dropdown shows stale hardcoded list instead of fresh API-fetched models.

**Evidence:** See `.planning/debug/gap-a04b-003-hardcoded-models-bypass.md`

---

## Execution Tasks

### Task 1: Remove Hardcoded Model Logic from ProviderSettings.tsx

**File:** `src/presentation/components/agent/ProviderSettings.tsx`

**Current (BROKEN):**
```tsx
const hardcodedModels = getHardcodedModelList(provider.id);
const useHardcoded = hardcodedModels !== null;
const models = useHardcoded
    ? hardcodedModels.map(formatHardcodedModel)
    : getProviderModels(provider.id);
```

**Target (FIXED):**
```tsx
// Always use API-loaded models from store
const models = getProviderModels(provider.id);
```

**Changes Required:**
1. Remove import of `getHardcodedModels`, `hasHardcodedModels`, `HardcodedModel` from hardcoded-models.ts
2. Remove `getHardcodedModelList` function (lines 72-75)
3. Remove `formatHardcodedModel` function (lines 78-87)
4. Remove hardcoded priority check (lines 191-195)
5. Simplify to always use `getProviderModels(provider.id)`
6. Remove `!useHardcoded` check for Refresh button (line 286)
7. Keep `CUSTOM_MODEL_VALUE` import if still needed
