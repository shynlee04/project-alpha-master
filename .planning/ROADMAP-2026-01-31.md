   - `src/domain/tools/types.ts` - ToolDefinition, ToolCall, ToolResult

2. Implement core tools:
```typescript
const TOOL_REGISTRY = {
  read_file: { category: 'file', permissions: ['read'], needsApproval: false },
  write_file: { category: 'file', permissions: ['write'], needsApproval: true },
  delete_file: { category: 'file', permissions: ['write'], needsApproval: true },
  list_files: { category: 'file', permissions: ['read'], needsApproval: false },

```

3. Tool permission levels:
   - `read` - Can read files, search RAG
   - `write` - Can create/modify/delete files
   - `execute` - Can run terminal commands

### Phase 2.2: Execution Pipeline (Day 2-4)

**Tasks:**
1. Create execution pipeline:
   - `src/domain/tools/executor.ts`
   - `src/domain/tools/approval.ts`

2. Implement approval workflow:
```typescript
async function executeToolCall(call: ToolCall, thread: Thread): Promise<ToolResult> {
  const tool = TOOL_REGISTRY[call.toolName];
  
  if (tool.needsApproval && !call.approved) {
    return { status: 'pending_approval', callId: call.id };
  }
  
  try {
    const output = await tool.execute(call.args);
    return {
      callId: call.id,
      output,
      sideEffects: tool.hasSideEffects ? trackSideEffects() : undefined,
    };
  } catch (error) {
    return { callId: call.id, error: error.message };
  }
}
```

3. Side effect tracking:
   - Track files created/modified/deleted
   - Embed in ToolResult for audit trail

const projectIndexes = new Map<string, OramaInstance>();

async function getOrCreateIndex(projectId: string): Promise<OramaInstance> {
  if (!projectIndexes.has(projectId)) {
    const index = await create({
      schema: {
        id: 'string',
        projectId: 'string',
        sourceType: 'string',
        sourceId: 'string',
        content: 'string',
        embedding: 'vector[512]',
      },

}
