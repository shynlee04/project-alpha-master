## Context

Via-Gent requires comprehensive multimodal AI capabilities to enable:
1. **Voice Input/Output** - Users speak to agents, agents respond with voice
2. **Image Processing** - Upload, analyze, and generate images in chat
3. **Audio/Video Processing** - Transcription, analysis, and playback
4. **Document Understanding** - PDFs, DOCX, and structured documents

### Current State Analysis

| Component | Status | Gap |
|-----------|--------|-----|
| TanStack AI Core | ✅ Installed | Package ready, not fully utilized |
| TanStack AI Gemini | ✅ Installed | Provider initialized but limited |
| `buildMultimodalMessage()` | ✅ Exists | Only handles text + images |
| Voice Input (STT) | ❌ Missing | No transcription tool |
| Voice Output (TTS) | ❌ Missing | No speech synthesis tool |
| Sequential Image Gen | ❌ Missing | No workflow orchestration |
| Context Window Mgmt | ❌ Missing | Potential 1M token overflow |

## Decision

### ADR Type: Integration Architecture

We will implement a **Unified Multimodal Pipeline** that:

1. **Extends TanStack AI** with custom tools for voice I/O
2. **Integrates Gemini 2.0/2.5** as primary multimodal provider
3. **Uses OpenAI Whisper** for transcription (Gemini fallback)
4. **Implements Context Window Manager** to prevent overflow
5. **Creates React Hooks** for voice I/O in UI components

### Model Selection Matrix

| Input Modality | Primary Model | Fallback Model | Notes |
|----------------|---------------|----------------|-------|
| Text only | gemini-2.5-flash | gpt-4o-mini | Cost-optimized |
| Text + Image | gemini-2.5-flash | gpt-4o | Vision required |
| Audio Input | whisper-1 | gemini-audio | Better accuracy |
| Audio Output | gemini-2.5-flash-tts | tts-1 | Native TTS |
| Video Input | gemini-2.5-pro | N/A | Only Gemini |
| Document | gemini-2.5-flash | claude-3.5 | PDF native |

## Consequences

### Positive Consequences

1. **Unified Multimodal Experience** - Single interface for all modalities
2. **Provider Flexibility** - Easy to swap between Gemini/OpenAI/Anthropic
3. **Context Efficiency** - Managed token usage, no overflow errors
4. **Voice Accessibility** - Users can interact hands-free
5. **Future-Proof** - Ready for video, document, and live streaming

### Negative Consequences

1. **Complexity** - More abstraction layers to maintain
2. **Latency** - Audio processing adds round-trip time
3. **Cost** - TTS/STT incur additional API costs
4. **Storage** - Audio blobs require more IndexedDB space

### Mitigation Strategies

| Risk | Mitigation |
|------|------------|
| Latency | Stream audio in chunks, show visual feedback |
| Cost | Implement usage limits, cache frequently used audio |
| Storage | Auto-expire audio after 24h, compress to opus |
| Complexity | Clear interface boundaries, extensive documentation |
