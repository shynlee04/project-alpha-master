# ADR-005: Governance Patterns and Autonomous Execution

**Status**: PROPOSED  
**Date**: 2026-01-07  
**Decision Type**: Operational Standard

## Context

Project requires consistent governance for:
- Architecture decision tracking
- Autonomous agent execution
- Code quality enforcement
- Technical debt management

## Decision

Establish **BMAD (Business Model & Agile Development) governance patterns** as the operational standard.

### Governance Structure

```
BMAD Core Master
├── Core Governance Module (MOD-A-CGOV)
├── Architecture Refactoring Module (MOD-B-ARCH)
├── Sprint & Feature Execution Module (MOD-C-SPRINT)
└── Integration & Testing Module (MOD-D-TEST)
```

### Time-Boxing Rules

| Level | Duration | Monitoring | On Timeout |
|-------|----------|------------|------------|
| Step | 5 min | Every 30s | Escalate to story |
| Story | 30 min | Every 1 min | Deep-investigation |
| Deep Investigation | 15 min | Every 30s | Split story |
| Epic | 4 hours | Every 30 min | Assess progress |

### Context Filtering (4-Tier TTL System)

| Tier | Name | TTL | description |
|------|------|-----|---------|
| 1 | Unchangeable | Permanent | Constitution, AGENTS.md |
| 2 | Controlled | Permanent | Core governance documents |
| 3 | Archival | 90 days | Sprint artifacts, research |
| 4 | Ephemeral | 24 hours | Temporary notes, scratch |

### Pre-Execution Validation Hook

```bash
# .claude/hooks/pre-execution.sh
#!/bin/bash

echo "Running governance validation..."

# 1. Check stale artifacts (TTL check with context recovery)
node .claude/hooks/scripts/check-artifact-freshness.js

# 2. Validate artifact size (god artifact detection >5000 lines)
node .claude/hooks/scripts/check-artifact-sizes.js

# 3. Tier 1 protection (constitution read-only check)
node .claude/hooks/scripts/check-tier1-protection.js

# 4. Time-boxing compliance (story duration monitoring)
node .claude/hooks/scripts/check-time-boxing.js

# 5. Context poisoning prevention (duplicate artifact detection)
node .claude/hooks/scripts/check-duplicate-artifacts.js

echo "Governance validation complete."
```

### Autonomous Decision Framework

Agents CAN make decisions without human approval for:
- Routine code refactoring within ADRs
- Test additions for existing functionality
- Documentation updates
- Dependency updates within semver
- File reorganization per ADR patterns

Agents MUST request approval for:
- New architectural patterns (not covered by ADRs)
- Breaking changes to public APIs
- Deletion of Tier 1/2 documents
- Changes exceeding 500 lines of code

## Rationale

1. **Consistency**: All decisions tracked and enforced
2. **Autonomy**: Clear boundaries for agent decision-making
3. **Quality**: Automated validation prevents debt accumulation
4. **Traceability**: All changes linked to ADRs
