# ADR-002: Single Source of Truth for State

**Status**: PROPOSED  
**Date**: 2026-01-07  
**Decision Type**: Architectural Standard

## Context

Phase 1 analysis revealed state fragmentation:
- **src/infrastructure/persistence/** - New canonical location (234 files)
- **src/stores/** - Legacy location (migration in progress)
- **src/lib/state/** - Deprecated, contains re-exports only

## Decision

**`src/infrastructure/persistence/` is the single source of truth for ALL state management.**

### Directory Structure

```
src/infrastructure/persistence/
├── dexie-db.ts                    # Canonical database (1,169 lines - TO BE DECOMPOSED)
├── dexie-db-types.ts             # Type definitions
├── dexie-db-migrations.ts         # Schema migrations
├── dexie-storage.ts              # Storage adapter
├── stores/
│   ├── use-app-store.ts          # Combined agents + providers store
│   ├── ide/
│   │   ├── useIDEStore.ts        # IDE workspace state
│   │   ├── ide-*.slice.ts        # Individual slices
│   │   └── ide-types.ts
│   ├── workspace/
│   │   ├── workspace-store.ts
│   │   └── useWorkspace*.ts
│   ├── providers/
│   │   ├── provider-*.slice.ts
│   │   └── types.ts
│   ├── conversation/
│   │   ├── useConversationStore.ts
│   │   └── slices/
│   └── agents/
│       └── slices/
└── events/
    └── event-bus.ts              # Cross-workspace events
```

### Import Pattern (Migration)

```typescript
// ❌ DEPRECATED - Shows console warning in dev mode
import { db, getDb } from '@/lib/state/dexie-db';

// ✅ CORRECT - New canonical path
import { db, getDb } from '@/infrastructure/persistence/dexie-db';
```

### Facade Pattern for Backward Compatibility

```typescript
// src/lib/state/dexie-db.ts (DEPRECATED - facade only)
import { db, getDb } from '@/infrastructure/persistence/dexie-db';

export { db, getDb };
console.warn('[DEPRECATED] Use @/infrastructure/persistence/dexie-db instead');
```

## Rationale

1. **Single Source**: Eliminates confusion about where state lives
2. **Clear Boundaries**: Infrastructure layer owns all persistence
3. **Migration Path**: Facade pattern preserves backward compatibility
4. **Testing**: Easier to mock single location

## Compliance Checklist

- [ ] All new stores created in `infrastructure/persistence/stores/`
- [ ] No new code imports from `src/stores/` or `src/lib/state/`
- [ ] Legacy locations only contain facade re-exports
- [ ] Deprecation warnings in console for legacy imports
