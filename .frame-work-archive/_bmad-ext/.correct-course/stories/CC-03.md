## Description

Fix the Chrome version check to use `>= 129` instead of `=== 129` to properly detect Chrome 130+ for FileSystemObserver features.

### User Story

I want to have FileSystemObserver features available,
So that I can benefit from native file system watching capabilities.

## Implementation Notes

### Current Bug
```typescript
// BEFORE (BUGGY):
navigator.userAgent.includes('Chrome/129')  // Exact match - fails on Chrome 130+
```

### Expected Fix
```typescript
// AFTER (FIXED):
const chromeMatch = navigator.userAgent.match(/Chrome\/(\d+)/);
const chromeVersion = chromeMatch ? parseInt(chromeMatch[1], 10) : 0;
return chromeVersion >= 129;
```
