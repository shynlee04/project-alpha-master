## Event Chain Example

### Agent Config Change Chain
```
User saves agent config
    ↓
AgentConfigDialog emits 'agent:config:change'
    ↓
Cross-workspace event bus broadcasts
    ├─→ AgentChatPanel (reloads agent)
    ├─→ SyncStatusPanel (updates status)
    └─→ PromptComposer (invalidates cache)
```

### File Sync Chain
```
User saves file
    ↓
FileTree emits 'files:changed'
    ├─→ CodeAnalysisBridge (re-analyzes)
    ├─→ SyncManager (syncs to WebContainer)
    └─→ IDEStore (updates open files)
```

## Optimization Opportunities

### 1. Event Debouncing
**Issue:** Multiple rapid events cause unnecessary re-renders
**Example:** `sync:progress` fires every 100ms
**Fix:** Debounce handler

### 2. Event Payload Size
**Issue:** Full objects passed instead of IDs
**Example:** `'files:changed'` sends full file objects
**Fix:** Pass IDs only, fetch on demand

### 3. Missing Cleanup
**Issue:** Some components may not unsubscribe
**Files:** code-analysis-bridge.ts, prompt-composer.ts
**Fix:** Add cleanup in useEffect return
