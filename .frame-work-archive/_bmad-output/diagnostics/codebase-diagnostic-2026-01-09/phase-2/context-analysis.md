## Critical Issue: Provider Value Not Memoized

### Evidence in ProjectContext.tsx
```typescript
const value = {
  project,
  setProject,
  updateProject,
  deleteProject,
  refreshProject,
  isLoading,
  error,
};

// ⚠️ NOT memoized - new object on every render
// This causes ALL consumers to re-render
```

### Evidence in WorkspaceContext.tsx
```typescript
const value = {
  workspace,
  setWorkspace,
  projectId,
  // ...
};

// ⚠️ NOT memoized - new object on every render
```

## Optimization Opportunities

| Context | Issue | Fix |
|---------|-------|-----|
| ProjectContext | No useMemo | `const value = useMemo(() => ({...}), [project])` |
| WorkspaceContext | No useMemo | `const value = useMemo(() => ({...}), [workspace])` |
| UnifiedWorkspaceContext | No useMemo | `const value = useMemo(() => ({...}), [workspace, project])` |
| SidebarContext | No useMemo | `const value = useMemo(() => ({...}), [collapsed])` |

## Re-render Impact Analysis

### Worst Case: ProjectContext Change
```
ProjectContext value changes
    ↓
All ProjectContext consumers re-render
    ├─→ MainSidebar (navigation)
    ├─→ FileTree (project files)
    ├─→ ChatPanel (project context)
    ├─→ IDE panels (project state)
    └─→ Multiple child components
```

**Estimated components re-rendering:** 10-20

### With Memoization (Fixed)
```
ProjectContext value changes (memoized)
    ↓
Only components using changed properties re-render
    ├─→ Components checking specific properties
    └─→ NOT entire subtree
```

**Estimated components re-rendering:** 2-5

---

## Recommendations

### P0: Memoize Provider Values
```typescript
// ProjectContext.tsx
const value = useMemo(() => ({
  project,
  setProject,
  updateProject,
  deleteProject,
  refreshProject,
  isLoading,
  error,
}), [project]); // Only recreate when project changes
```

### P1: Split Contexts
- Split ProjectContext into smaller contexts
- Separate read-only from writable contexts
- Reduce re-render scope

### P2: Use Selectors
- Implement context selector pattern
- Components only re-render when their specific data changes
