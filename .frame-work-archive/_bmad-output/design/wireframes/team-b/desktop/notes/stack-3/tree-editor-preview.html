2024-01-18 Daily Journal

Morning Reflections

Today I started working on Via-Gent, my personal knowledge management system. The goal is to create a seamless workspace that combines note-taking with AI-assisted writing.

Key Insights

  • Progressive disclosure helps manage complexity
  • 8-bit design creates focus through constraints
  • Agent collaboration is the future
  • File system access enables powerful workflows

Storage Strategy

Based on research, implementing auto-detection for storage type:

Desktop uses File System Access API, mobile falls back to IndexedDB for offline-first behavior.

Architecture Pattern

Layer Purpose
Presentation React components and UI logic
Domain Business entities and services
Infrastructure External integrations

Code Snippet

interface PlatformContract {
  deviceType: 'desktop' | 'mobile' | 'tablet';
  storageType: 'fsa' | 'indexeddb';
}

const platform = getPlatformContract();

Tomorrow's Goals

  • Complete FSA storage adapter
  • Design AI chat integration
  • Implement workspace selector
