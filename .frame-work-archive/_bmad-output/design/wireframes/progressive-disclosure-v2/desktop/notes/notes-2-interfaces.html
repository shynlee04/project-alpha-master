Progressive Disclosure

Progressive disclosure is a design pattern where only essential information is shown initially, with additional information revealed through user interaction. This approach reduces cognitive load and improves usability.

Key Principles

  • Show only what users need right now
  • Make additional features discoverable
  • Provide clear visual hierarchy
  • Use familiar interaction patterns

Implementation in Via-Gent

Via-Gent applies progressive disclosure across all workspaces:

  • IDE: Tree + Editor (minimal) → Add Preview/Terminal/Chat as needed
  • Notes: List + Editor (zen mode) → Add Preview/Chat for research
  • Mobile: Single panel focus → Swipe navigation

This approach ensures that beginners aren't overwhelmed while power users have quick access to all features.

Code Example

// Progressive disclosure in React
const [showAdvanced, setShowAdvanced] = useState(false);

return (
  <div>
    <Button onClick={() => setShowAdvanced(!showAdvanced)}>
      {showAdvanced ? 'Hide Advanced' : 'Show Advanced'}
    </Button>
    {showAdvanced && <AdvancedOptions />}
  </div>
);

The key is to start simple and reveal complexity only when users explicitly request it.
