Can you explain the difference between useMemo and useCallback?
🤖
Great question!

useMemo memoizes a computed value - it recalculates only when dependencies change.

useCallback memoizes a function reference - useful when passing callbacks to optimized child components.

Think: useMemo = value, useCallback = function!
U
When should I use useMemo over useCallback?
🤖
Use useMemo when:
• You have expensive calculations
• You're deriving data from state/props
• You want to avoid recalculating on every render

Use useCallback when:
• You're passing functions to child components wrapped in React.memo
• Functions are dependencies of other hooks
• You need stable function references
