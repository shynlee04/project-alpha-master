Related Flashcards
Question
What is the purpose of useState?
Answer
useState adds state variables to functional components, allowing you to store and update data that changes over time.
Question
What are the two arguments useEffect accepts?
Answer
A callback function and an optional dependency array that controls when the effect runs.
Question
When should you use useMemo?
Answer
When you have expensive computations that should only re-run when dependencies change.
Question
What is the difference between useMemo and useCallback?
Answer
useMemo memoizes computed values, while useCallback memoizes function references.
