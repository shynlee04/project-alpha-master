Getting Started with React

React is a JavaScript library for building user interfaces. Learn how to create your first React application.

Installation

To create a new React project, you can use Vite:

npm create vite@latest my-app -- --template react

Your First Component

A React component is a JavaScript function that returns markup:

function MyButton() {'{'} return (<button>I'm a button</button>); {'}'}
