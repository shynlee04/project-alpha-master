## Migration Pattern

### BEFORE (OLD - workspace-centric)

```typescript
// src/routes/notes.$projectId.tsx
import { ProjectProvider } from '@/lib/workspace/ProjectContext';

export function NotesProjectRoute() {
  return (
    <ProjectProvider project={project as Project | null} workspace="notes">
      <NotesPage />
    </ProjectProvider>
  );
}
```

### AFTER (NEW - project-centric)

```typescript
// src/routes/notes.$projectId.tsx
import { ProjectContextProvider } from '@/infrastructure/context/project-context';
import { FileTreePlugin } from '@/plugins/filetree';

export function NotesProjectRoute() {
  const { project } = Route.useLoaderData();

  return (
    <ProjectContextProvider projectId={project.id}>
      <NotesLayout>
        <FileTreePlugin.MainComponent />
        <NotesEditor />
      </NotesLayout>
    </ProjectContextProvider>
  );
}
```

## Implementation Strategy

### Phase 1: Extract FileTree to Plugin (2 hours)
1. Create `src/plugins/filetree/` directory
2. Copy FileTree component logic to `FileTreePlugin.tsx`
3. Remove workspace-specific dependencies:
   - Replace `useWorkspaceSync()` with ProjectContext
   - Remove imports from `@/lib/workspace`
   - Use `ProjectContext.gateway` for file operations
4. Implement FeaturePlugin interface:
   - Define plugin object with required properties
   - Map MainComponent to extracted FileTree
   - Set requirements (storageType: 'any', deviceType: 'any')
5. Create plugin types in `types.ts`
6. Export plugin from `index.ts`

### Phase 2: Register Plugin (30 minutes)
1. Import `registerPlugin` from plugin registry
2. Call `registerPlugin(fileTreePlugin)` at app startup
3. Verify registration succeeds

### Phase 3: Migrate notes.$projectId Route (2 hours)
1. Import `ProjectContextProvider` from `@/infrastructure/context`
2. Remove `ProjectProvider` import from `@/lib/workspace`
3. Wrap route in `ProjectContextProvider` instead
4. Integrate `FileTreePlugin.MainComponent` into route layout
5. Test that route loads and FileTree renders

### Phase 4: Verification (1.5 hours)
1. Run TypeScript check: `pnpm tsc --noEmit`
2. Verify old import removed: `grep -n "from '@/lib/workspace/ProjectContext'" src/routes/notes.\$projectId.tsx`
3. Verify new import present: `grep -n "from '@/infrastructure/context" src/routes/notes.\$projectId.tsx`
4. Manual test: Navigate to `/notes/$projectId`, verify FileTree works
5. Test file selection and refresh operations
