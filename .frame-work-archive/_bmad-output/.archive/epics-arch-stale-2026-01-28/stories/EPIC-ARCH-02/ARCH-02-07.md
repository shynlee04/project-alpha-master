## Description

Extract Terminal component into standalone plugin following FeaturePlugin architecture per ADR-034. Terminal plugin will integrate with xterm.js and WebContainer/native terminal.

## Context (from EPIC-ARCH-02)

Terminal component currently exists in:
- `src/presentation/components/terminal/TerminalPanel.tsx` - Panel wrapper with tabs
- `src/presentation/components/ide/XTerminal.tsx` - xterm.js integration

Terminal plugin must:
- Implement FeaturePlugin interface (ADR-034 Section 3)
- Only be available for desktop FSA projects (deviceType: 'desktop', storageType: 'fsa')
- Connect to WebContainer or native terminal
- Follow exact same structure as FileTreePlugin, MonacoPlugin, NotesPlugin

export const terminalPlugin: FeaturePlugin = {
  id: 'terminal',
  name: 'Terminal',
  icon: <TerminalIcon />,
