## Problem Statement

Currently, plugins are implemented but there is no layout container to render them. We need:

1. **Flexible Layout Engine** - Support multiple layout configurations (1-5 plugins)
2. **Resizable Panels** - Using react-resizable-panels for 8-bit design compliant panels
3. **Layout Persistence** - Save and restore layout per project
4. **Plugin Management** - Add/remove plugins UI with drag-drop reordering
5. **Responsive Design** - Panels resize based on available space

---

## Solution

Create PluginLayout container component with:

### PluginLayout.tsx
Main layout container that:
- Receives list of active plugins (from ProjectContext or project settings)
- Renders plugins using react-resizable-panels
- Supports 4 layout modes (1-column, 2-column, 3-column, 2+1)
- Persists layout configuration per project

### PluginPanel.tsx
Individual panel wrapper that:
- Wraps plugin.MainComponent
- Handles panel-specific UI (resize handle, close button, header)
- Manages plugin lifecycle (onMount/onUnmount calls)
- Validates plugin requirements (minWidth, maxInstances)

### PluginLayoutStore.ts
Zustand store for:
- Active plugins list (order preserved)
- Layout mode (1-column, 2-column, 3-column, 2+1)
- Panel sizes (persisted)
- Add/remove plugin actions

### Plugin Layout Store (Zustand)

```typescript
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

interface PluginLayoutState {
  activePlugins: string[]; // Plugin IDs in order
  layoutMode: '1-column' | '2-column' | '3-column' | '2+1';
  panelSizes: Record<string, number>; // Plugin ID -> size percentage

  // Actions
  addPlugin: (pluginId: string) => void;
  removePlugin: (pluginId: string) => void;
  reorderPlugin: (fromIndex: number, toIndex: number) => void;
  setLayoutMode: (mode: string) => void;
  setPanelSize: (pluginId: string, size: number) => void;
}

export const usePluginLayoutStore = create<PluginLayoutState>()(
  persist(
    (set) => ({
      activePlugins: [],
      layoutMode: '2-column',
      panelSizes: {},

      addPlugin: (pluginId) => set((state) => ({
        activePlugins: [...state.activePlugins, pluginId],
      })),

      removePlugin: (pluginId) => set((state) => ({
        activePlugins: state.activePlugins.filter((id) => id !== pluginId),
      })),

      reorderPlugin: (fromIndex, toIndex) => set((state) => {
        const newPlugins = [...state.activePlugins];
        const [moved] = newPlugins.splice(fromIndex, 1);
        newPlugins.splice(toIndex, 0, moved);
        return { activePlugins: newPlugins };
      }),

      setLayoutMode: (mode) => set({ layoutMode: mode }),
      setPanelSize: (pluginId, size) => set((state) => ({
        panelSizes: { ...state.panelSizes, [pluginId]: size },
      })),
    }),
    { name: 'plugin-layout-storage' }
  )
);
```
