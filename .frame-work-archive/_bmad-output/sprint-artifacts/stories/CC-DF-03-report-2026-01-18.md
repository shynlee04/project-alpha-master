## 🏗️ IMPLEMENTATION DETAILS

### Tool Functions Implemented

#### `listNotes(projectId, limit?, offset?)`
- **Input**: Zod schema with `projectId` (required), `limit`, `offset` (optional)
- **Output**: `ToolResult<{ notes: NoteMetadata[], total: number }>`
- **Operations**:
  1. Creates StorageGateway for project
  2. Lists files matching `notes/*.md`
  3. Parses YAML frontmatter from each file
  4. Extracts metadata (title, dates, parentId)
  5. Sorts by `updatedAt` descending
  6. Applies pagination (offset, limit)
  7. Returns note metadata without content (performance)

#### `readNote(noteId, projectId)`
- **Input**: Zod schema with `noteId`, `projectId`
- **Output**: `ToolResult<{ note: NoteData }>`
- **Operations**:
  1. Creates StorageGateway for project
  2. Builds path: `notes/{noteId}.md`
  3. Reads file using gateway
  4. Parses markdown frontmatter and content
  5. Returns full note with metadata and content

#### `writeNote(noteId?, title, content, projectId, parentId?)`
- **Input**: Zod schema with `noteId` (optional), `title`, `content`, `projectId`, `parentId` (optional)
- **Output**: `ToolResult<{ note: NoteData }>`
- **Operations**:
  1. Creates StorageGateway for project
  2. Generates `noteId` via `crypto.randomUUID()` if not provided
  3. Creates NoteRecord from input data
  4. Converts NoteRecord to markdown using `formatNoteForStorage()`
  5. Converts markdown string to Uint8Array
  6. Writes to `notes/{noteId}.md`

#### `deleteNote(noteId, projectId)`
- **Input**: Zod schema with `noteId`, `projectId`
- **Output**: `ToolResult<{ deletedNoteId, deletedTitle }>`
- **Operations**:
  1. Creates StorageGateway for project
  2. Builds path: `notes/{noteId}.md`
  3. Reads note to get title (for response)
  4. Deletes file using gateway

- **Expected**: `read`, `write`, `delete`
- **Actual**: `readFile`, `writeFile`, `deleteFile`
- **Impact**: Implementation code cannot compile due to interface mismatch
- **Recommendation**: Fix `src/domain/interfaces/storage-adapter.interface.ts` method names to match FSA adapter implementation

**Fix Required**:
```typescript
// Current (causes errors in note-commands.ts)
interface StorageAdapter {

  writeFile(path: string, content: Uint8Array): Promise<void>;
  deleteFile(path: string): Promise<void>;
  listFiles(pattern: string): Promise<string[]>;
  // ...
}

// Should be (to match FSA adapter)
interface StorageAdapter {
  read(path: string): Promise<FileContent>;  // Renamed from readFile

  delete(path: string): Promise<void>;  // Renamed from deleteFile
  listFiles(pattern: string): Promise<string[]>;
  // ...
}
```
