## 1. Problem Statement

The main content area currently hardcodes Monaco without any Activity Bar. Per UX Spec Section 8.4, there should be a **horizontal Activity Bar TOP** that allows switching between Notes, Monaco (Code), and Preview plugins in the main content area.

### Current State

```tsx
// $projectId.tsx line 279
mainContent={<MonacoMain width={0} height={0} />}  // HARDCODED - No switching!
```

### Target State

```
+----------------------------------------------------------+
|     [Activity Bar TOP - Horizontal 48px]                 |
|  [Notes] [Monaco] [Preview]                              |
+----------------------------------------------------------+
|                                                          |
|               Active Plugin Content                      |
|               (Notes / Monaco / Preview)                 |
|                                                          |
+----------------------------------------------------------+
```

---

## 2. Acceptance Criteria

- [ ] `ActivityBarTop.tsx` component created with horizontal orientation
- [ ] Height: 48px, full width of main content area
- [ ] Icons for Notes, Monaco (Code), Preview (Eye)
- [ ] Active indicator: 2px bottom border (per UX Spec 8.1)
- [ ] Clicking icon changes active plugin in main content
- [ ] Supports `aria-label` and keyboard navigation
- [ ] 8-bit styling: sharp corners, pixel borders, no gradients

---

## 3. Technical Requirements

### 3.1 TypeScript Interface

```typescript
interface ActivityBarTopItem {
  pluginId: PluginId;
  icon: ReactNode;
  label: string;
  shortcut?: string; // 'Cmd+1', 'Cmd+2', etc.
}

interface ActivityBarTopProps {
  items: ActivityBarTopItem[];
  activePluginId: PluginId | null;
  onItemClick: (pluginId: PluginId) => void;
  className?: string;
}
```

| File | Action |
