## 🔍 Step 2A: Pre-Planning Research (MCP Server Usage)

### Research Findings

**1. Vitest Mocking Patterns for File System**:
- Source: https://vitest.dev/guide/mocking/file-system
- **Key Recommendation**: Use `memfs` for file system mocking (creates in-memory file system)
- Vitest doesn't provide built-in file system mocking API
- Alternative: Manual `vi.mock()` of fs module
- **Decision**: Used manual in-memory `MockFSAGateway` class to avoid `memfs` dependency

**2. Existing Test Patterns in Codebase**:
- Files analyzed:
  - `src/lib/agent/tools/__tests__/note-commands.test.ts` - Shows pattern for mocking storage operations
  - `src/infrastructure/filesystem/__tests__/storage-gateway-factory.test.ts` - Shows factory pattern tests
  - `src/infrastructure/persistence/__tests__/dexie-db-class.test.ts` - Shows DexieDB mock patterns

**3. Mocking Strategies Identified**:
- **DexieDB Mocking**: Use simple `Map<string, NoteRecord>` for in-memory persistence
- **FSA Gateway Mocking**: Implement `StorageGateway` interface with `Map<string, Uint8Array>` for file storage
- **vi.mock() vs class implementation**: Class-based mocks provide better test isolation than vi.mock()
- **beforeEach/afterEach**: Clear mocks and reset state between tests for isolation

**4. Best Practices Discovered**:
- Always call `vi.clearAllMocks()` in `beforeEach()` to prevent test interference
- Use descriptive test names matching acceptance criteria
- Test both success and error paths
- Mock FileEntry, FileChangeEvent, WatchHandle types for StorageGateway

## 🎯 Mock Strategy Documentation

### MockFSAGateway Class

**Purpose**: Simulate FSA Gateway behavior without actual file system access.

**Implementation Details**:
- **Storage**: `Map<string, Uint8Array>` - in-memory file store
- **Changes**: `FileChangeEvent[]` - tracks all file operations
- **Watcher**: `FileChangeCallback | null` - callback for file watching

**Method Implementations**:
```typescript
read(path: string): Promise<Uint8Array>  // Read file from memory
write(path: string, data: Uint8Array): Promise<void>  // Write file to memory
delete(path: string): Promise<void>  // Delete file from memory
list(pattern: string): Promise<FileEntry[]>  // List files matching pattern
exists(path: string): Promise<boolean>  // Check if file exists
watch(callback: FileChangeCallback): WatchHandle  // Watch for file changes
```

**Test Helper Methods**:
```typescript
getChanges(): FileChangeEvent[]  // Get all recorded changes
clearChanges(): void  // Clear change tracking
simulateExternalChange(path, kind): void  // Simulate external file change
reset(): void  // Reset to initial state
seedFiles(files, noteId?): Promise<void>  // Populate with mock data
getFileCount(): number  // Get number of files stored
isStopped(): boolean  // Check if watching stopped
```
