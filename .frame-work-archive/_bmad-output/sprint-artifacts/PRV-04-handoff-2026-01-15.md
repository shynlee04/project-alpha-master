## Key Implementation Details

### Zustand Persist Pattern
The workspace provider preferences use zustand's persist middleware to save to localStorage under the key `workspace-provider-preferences`. This ensures preferences persist across sessions.

### Workspace Preference Structure
```typescript
interface WorkspaceProviderPreference {
  preferredProviderId: string | null;  // null = use global default
  fallbackProviders: string[] | null;   // null = use global default
  strictMode: boolean;                  // no fallback if preferred lacks key
}
```

### Strict Mode
When strict mode is enabled for a workspace, only the preferred provider is used - no fallback to other providers. This is useful for environments that require a specific provider.
