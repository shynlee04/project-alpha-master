Thiết kế Component React

Trong dự án này, chúng ta sẽ áp dụng các nguyên tắc thiết kế component theo chuẩn hiện đại với TypeScript và React 19.

Nguyên tắc chính

  • Single Responsibility - Mỗi component chỉ làm một việc
  • Reusable - Component có thể tái sử dụng
  • Testable - Dễ dàng viết unit test
  • Accessible - Tuân thủ WCAG AA

Ví dụ Code

interface ButtonProps {
  variant: 'primary' | 'secondary';
}
