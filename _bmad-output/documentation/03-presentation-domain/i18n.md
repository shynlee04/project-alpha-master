# Internationalization Documentation

## Overview

The application uses i18next for internationalization with support for English (en) and Vietnamese (vi). The presentation layer has 387 components using translation functions.

## Configuration

### Files

| File | Description |
|------|-------------|
| `src/i18n/en.json` | English translations |
| `src/i18n/vi.json` | Vietnamese translations |
| `src/i18n/index.ts` | i18n configuration |

### Setup

```typescript
// src/i18n/index.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import en from './en.json';
import vi from './vi.json';

i18n.use(initReactI18next).init({
  resources: { en: { translation: en }, vi: { translation: vi } },
  lng: 'en',
  fallbackLng: 'en',
  interpolation: { escapeValue: false },
});
```

## Translation Usage

### Basic Usage

```typescript
import { useTranslation } from 'react-i18next';

function Component() {
  const { t } = useTranslation();
  
  return <button>{t('actions.save')}</button>;
}
```

### Interpolation

```typescript
// JSON: "greeting.name": "Hello, {{name}}!"
t('greeting.name', { name: 'John' }); // "Hello, John!"

// JSON: "error.count": "{{count}} errors found"
t('error.count', { count: 5 }); // "5 errors found"
```

### Pluralization

```typescript
// JSON: "messages.count_one": "{{count}} message"
//       "messages.count_other": "{{count}} messages"
t('messages.count', { count: 1 }); // "1 message"
t('messages.count', { count: 5 }); // "5 messages"
```

### Nested Keys

```typescript
// JSON: "agents.config.tabs.basic": "Basic"
t('agents.config.tabs.basic'); // "Basic"
```

## Component i18n Usage

### Example: Button Component

```tsx
// src/presentation/components/ui/button.tsx
import { useTranslation } from 'react-i18next';

export function Button({ children, ...props }) {
  const { t } = useTranslation();
  
  return <button {...props}>{children || t('actions.save')}</button>;
}
```

### Example: Form Field

```tsx
// src/presentation/components/agent/AgentBasicInfoTab.tsx
import { useTranslation } from 'react-i18next';

export function AgentBasicInfoTab() {
  const { t } = useTranslation();
  
  return (
    <div>
      <label>
        {t('agents.config.name.label')}
        <input 
          aria-label={t('agents.config.name.ariaLabel')}
          placeholder={t('agents.config.name.placeholder')}
        />
      </label>
    </div>
  );
}
```

### Example: Status Messages


## Adding New Translations

### 1. Add Key to Component

```tsx
// Component code
const { t } = useTranslation();
return <div>{t('newFeature.title')}</div>;
```

### 2. Extract Keys

```bash
pnpm i18n:extract
```

### 3. Update Translation Files

```json
// src/i18n/en.json
{
  "newFeature.title": "New Feature"
}

// src/i18n/vi.json
{
  "newFeature.title": "Tính năng mới"
}
```

## Best Practices

### 1. Use Translation Keys, Not Raw Text

```tsx
// Good
<button>{t('actions.save')}</button>

// Bad - Not translatable
<button>Save</button>
```

### 2. Provide Context

```tsx
// Good - Clear purpose
t('agents.config.apiKey.label')  // API Key

// Bad - Ambiguous
t('api.key')  // What kind of API?
```

### 3. Handle Plurals

```tsx
// Good
t('validation.title', { count: errors.length });

// JSON
"validation.title_one": "{{count}} validation issue"
"validation.title_other": "{{count}} validation issues"
```

### 4. Include ARIA Labels

```tsx
// Good - Accessible
<button 
  aria-label={t('actions.delete')}
  aria-describedby="delete-help-text"
>
  <TrashIcon />
</button>

// Bad - Not accessible
<button><TrashIcon /></button>
```

### 5. Use Named Export for Namespaces

```tsx
// Good - Organized
import { useTranslation } from 'react-i18next';
const { t } = useTranslation('agents');

// Usage
t('config:tabs.basic');

// Bad - Mixing namespaces
const { t } = useTranslation();
t('agents.config.tabs.basic');
```

## Language Switcher

**Location:** `src/presentation/components/LanguageSwitcher.tsx`

**Implementation:**
```tsx
import { useTranslation } from 'react-i18next';

export function LanguageSwitcher() {
  const { i18n } = useTranslation();
  
  const changeLanguage = (lng: string) => {
    i18n.changeLanguage(lng);
  };
  
  return (
    <select 
      value={i18n.language}
      onChange={(e) => changeLanguage(e.target.value)}
    >
      <option value="en">English</option>
      <option value="vi">Tiếng Việt</option>
    </select>
  );
}
```

## Developer Notes

### Running Extraction

```bash
# Extract translation keys from source
pnpm i18n:extract

# This updates src/i18n/en.json with new keys
```

### Namespace Organization

For large features, use namespaces:

```tsx
// Component
const { t } = useTranslation('agents');

// JSON file structure
{
  "agents": {
    "config": { ... },
    "manager": { ... }
  }
}
```

### Performance

- i18next is initialized once at app start
- Translations are loaded asynchronously
- Use `useTranslation` hook (not instance) for tree-shaking
