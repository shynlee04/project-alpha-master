## Patterns Applied

### 1. Type-Only Import Redirection
**Pattern**: Redirect type imports from barrel exports to source files
**Example**:
```typescript
// Before (causes circular dependency)
import type { SubjectCategory } from './subject-classifier';

// After (breaks cycle)
import type { SubjectCategory } from './subject-classifier-types';
```

### 2. Domain Type Extraction
**Pattern**: Extract shared types to central types file
**Example**:
```typescript
// Created: types.ts
export type EventStatus = 'idle' | 'loading' | 'success' | 'error' | 'warning'
export interface EventIndicatorProps { ... }

// Updated imports in 10+ files
import type { EventStatus, EventIndicatorProps } from './types';
```

### 3. Static Method Pattern
**Pattern**: Move helper function to static method to break import cycle
**Example**:
```typescript
// Before: Helper imports class, class re-exports helper
// query-optimizer-helpers.ts
import { QueryOptimizer } from './query-optimizer';
export function createWeightedQuery(...) {
  const optimizer = new QueryOptimizer();
  ...
}

// query-optimizer.ts
export { createWeightedQuery } from './query-optimizer-helpers';

// After: Static method, helper re-exports
// query-optimizer.ts
export class QueryOptimizer {
  static createWeightedQuery(...) {
    const optimizer = new QueryOptimizer();
    ...
  }
}
export const createWeightedQuery = QueryOptimizer.createWeightedQuery.bind(QueryOptimizer);
```

### 4. Barrel Export Cleanup
**Pattern**: Remove component from barrel export to break re-export cycle
**Example**:
```typescript
// Before: IDELayout/index.ts
export { IDELayout } from '../IDELayoutMain';  // Creates cycle

// After: IDELayout/index.ts
// IDELayout not exported from barrel (import directly from IDELayoutMain.tsx)
```

## Lessons Learned

1. **Type-Only Imports**: Most circular dependencies can be broken by redirecting type imports to source files instead of barrel exports
2. **Domain Type Extraction**: Moving types to central files (`types.ts`) improves organization and eliminates multiple import cycles at once
3. **Static Methods**: Helper functions that create instances of a class can be moved to static methods to break import chains
4. **Generated Files**: Always exclude auto-generated files (routeTree.gen.ts, generated GraphQL, etc.) from circular dependency checks
5. **Batch Fixing**: Similar patterns can be fixed in batch using sed/bash scripts for efficiency
