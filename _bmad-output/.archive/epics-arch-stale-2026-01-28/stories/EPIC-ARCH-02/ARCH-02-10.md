## Description

**As a** user navigating to a project
**I want** to access a unified route `/$projectId` that loads my selected plugins
**So that** I can customize my workspace layout without being forced into specific workspace types (IDE, Notes, etc.)

**Per ADR-034 Section 5:**
This is the FINAL unified route that replaces 4 workspace-specific routes:
- `/ide/$projectId`
- `/notes/$projectId`
- `/knowledge/$projectId` (deferred)
- `/study/$projectId` (deferred)

**Route Behavior:**
1. Load `ProjectContextProvider` (from ARCH-02-03)
2. Render `PluginLayout` (from ARCH-02-09) with user's selected plugins
3. Support layout presets via query params (`?layout=ide`, `?layout=notes`)
4. Persist user's plugin selection per project
5. Old routes redirect with query param to preserve layout preference

## Implementation Plan

### 1. Create `src/routes/$projectId.tsx`

```typescript
// Route pattern: /$projectId
export const Route = createFileRoute('/$projectId')({
  // Load project data
  loader: async ({ params }) => {
    const { projectId } = params;
    const record = await db.projects.get(projectId);
    if (!record) {
      throw redirect({ to: '/hub' });
    }
    const project = fromRecord(record);
    return { project };
  },

  // Component: Render unified project route
  component: () => (
    <ErrorBoundary>
      <UnifiedProjectRoute />
    </ErrorBoundary>
  ),
});

function UnifiedProjectRoute() {
  const { projectId } = Route.useParams();
  const { project } = Route.useLoaderData();
  const search = Route.useSearch<{ layout?: 'ide' | 'notes' }>();

  // Determine layout preset from query param OR project settings
  const layoutPreset = search.layout || project.defaultLayout || 'ide';

  return (
    <ProjectContextProvider projectId={projectId}>
      <PluginLayout initialLayout={layoutPreset} />
    </ProjectContextProvider>
  );
}
```

### 2. Modify Old Routes for Redirects

```typescript
// src/routes/ide.$projectId.tsx
beforeLoad: async ({ params, search }) => {
  const { projectId } = params;
  // Check if already on new route
  if (search?.layout === 'ide') {
    return; // No redirect needed
  }
  // Redirect to new route with layout preset
  throw redirect({ to: `/$projectId`, search: { layout: 'ide' } });
}
```

### 3. Layout Preset Support

When `?layout=ide`:
- Set activePlugins: `['filetree', 'monaco', 'terminal', 'chat']`
- Set layoutMode: `'2+1'`

When `?layout=notes`:
- Set activePlugins: `['filetree', 'notes', 'chat']`
- Set layoutMode: `'2-column'`

When no layout param:
- Use persisted plugin selection from project settings
- Default to empty state (user adds plugins manually)

### 4. Route Registration

Add to `AppInitializer.tsx`:
```typescript
import { Route as ProjectRoute } from '@/routes/$projectId';

// Register in router
<Router>
  <Route path="/hub" component={HubRoute} />
  <Route path="/$projectId" component={ProjectRoute} />  // NEW UNIFIED ROUTE
  <Route path="/ide/$projectId" component={IDERoute} />  // REDIRECT ROUTE
  <Route path="/notes/$projectId" component={NotesRoute} />  // REDIRECT ROUTE
</Router>
```
