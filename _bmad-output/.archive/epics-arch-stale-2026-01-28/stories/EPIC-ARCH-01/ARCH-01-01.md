## Agentic & UX Context (REQUIRED)

### The User Journey

**Answer these 6 questions to define the user flow:**

1. **User starts at**: Any page in the application
   - User can be on Hub, Notes, IDE, or any route

2. **User performs**: Clicks a navigation link or triggers a redirect
   - Examples: "Open Project" button, "Switch Workspace", "Back" button

3. **System shows**: Immediate navigation via SPA (no page reload)
   - Spinner may appear briefly during transition
   - URL updates in address bar
   - New content renders

4. **Result appears**: Target route/component
   - User sees the destination page
   - State preserved where applicable

5. **User then**: Continues work on target page
   - No need to re-authenticate or reload
   - Full SPA experience maintained

6. **If it fails**: Full page reload occurs (current broken behavior)
   - User loses unsaved state
   - Hydration errors in console
   - Experience is janky
