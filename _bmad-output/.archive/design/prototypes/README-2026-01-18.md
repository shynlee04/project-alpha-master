# UX Prototypes Folder Structure

**Created**: 2026-01-18  
**Purpose**: Hierarchical organization of production-ready HTML prototypes  
**Design System**: 8-bit aesthetic with WCAG accessibility

---

## Directory Structure

```
prototypes/
├── desktop/              # Desktop layouts (1024px+)
│   ├── ide/             # IDE workspace prototypes
│   ├── notes/           # Notes workspace prototypes
│   ├── knowledge/       # Knowledge workspace prototypes
│   ├── study/           # Study workspace prototypes
│   ├── workspace-mix/   # Hybrid workspace layouts
│   ├── en/              # English variants (default)
│   └── vi/              # Vietnamese translations
│
├── tablet/               # Tablet layouts (768-1024px)
│   ├── ide/
│   ├── notes/
│   ├── knowledge/
│   └── study/
│
└── mobile/              # Mobile layouts (<768px)
    ├── ide/
    ├── notes/
    ├── knowledge/
    └── study/
```

---

## Naming Convention

HTML files follow this pattern:
```
stack-{N}-{panels}.html
```

Where:
- `{N}` = Number of panels/sections (2-5)
- `{panels}` = Hyphen-separated list of visible panels

### Examples

- `stack-2-tree-editor.html` (Tree + Editor)
- `stack-3-tree-editor-preview.html` (Tree + Editor + Preview)
- `stack-4-tree-editor-preview-terminal.html` (Tree + Editor + Preview + Terminal)
- `stack-5-tree-editor-preview-terminal-chat.html` (All 5 panels)

---

## Panel Types

| Panel | Description | Workspaces |
|-------|-------------|------------|
| `tree` | File/Project tree | IDE, Notes, Knowledge, Study |
| `editor` | Code/Note editor | IDE, Notes |
| `preview` | Live preview | IDE, Notes |
| `terminal` | Command terminal | IDE, Notes |
| `chat` | AI chat panel | All workspaces |
| `sources` | Source card grid | Knowledge |
| `dashboard` | Stats/dashboard cards | Study |
| `quiz` | Quiz interface | Study |
| `flashcards` | Flashcard interface | Study |

## Design Requirements

### 8-bit Aesthetic
- **Border radius**: `0` or `2px` only
- **Shadows**: `4px 4px 0 0 #000` (pixel shadows)
- **No glassmorphism**: Solid opaque colors only

### Typography
- **UI elements**: JetBrains Mono
- **Prose text**: Geist Sans

### Responsive
- **Mobile-first**: Portrait phone support (375px+)
- **Breakpoints**: 
  - Mobile: <768px
  - Tablet: 768-1024px
  - Desktop: >1024px

### Accessibility (WCAG AA)
- **Touch targets**: Minimum 44x44px
- **Color contrast**: 4.5:1 minimum
- **Focus states**: Visible keyboard navigation
- **Screen reader**: Proper ARIA labels
