## Acceptance Criteria Summary

### P0-001: SSR Vault Bypass

**Given** vault not initialized during SSR  
**When** RAG queries run  
**Then** show "Loading credentials..." and auto-retry  

### P0-002: Connection Timeout

**Given** user saves API key  
**When** testing connection  
**Then** complete within 10s with specific error (401/403/timeout)  

### P0-003: Key Format Validation

**Given** user enters invalid key format  
**When** saving  
**Then** show warning dialog with "Save Anyway" option  

### P0-004: Hydration Race

**Given** app starting  
**When** multiple stores hydrate  
**Then** use unified hydration hook, show loading state  

### P0-005: IndexedDB Recovery

**Given** DB corrupted  
**When** opening  
**Then** auto-delete and recreate, notify user  

### P0-006: Model Cache

**Given** models fetched  
**When** page reloads  
**Then** use cached models if <24h old
