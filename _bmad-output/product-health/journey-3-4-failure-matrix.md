## Spec-Driven Acceptance Checks (Journeys 3 & 4)

### P0-002: Connection Test Timeout

**AC**: 10-second timeout with user feedback
```gherkin
Given user saves API key
When testing connection
Then complete within 10 seconds max
And show loading spinner with "Testing connection..."
If timeout: show "Connection timed out" with retry
If 401: show "Invalid API key"
If 403: show "Access denied - check permissions"
```

### P0-003: Key Format Validation

**AC**: Warn on invalid format
```gherkin
Given user enters key for Gemini
When key doesn't match ^AIza pattern
Then show: "This doesn't look like a valid Gemini key"
And allow "Save Anyway" or "Edit"
```

### P0-007: Global Indexing Indicator

**AC**: Visible in all workspaces
```gherkin
Given indexing is in progress
When user switches to any workspace
Then show persistent indicator:
- "Indexing (2/10 documents)"
- Or spinner in status bar
And clicking opens indexing progress panel
And user can continue working while indexing
```
