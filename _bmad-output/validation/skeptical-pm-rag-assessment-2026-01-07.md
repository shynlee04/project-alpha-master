### BLOCKER 4: Embedding Service Doesn't Auto-Connect to Credential Vault

**File**: `src/lib/rag/embedding-service.ts:517-532`

```typescript
export async function createEmbeddingService(
    apiKey?: string  // ⚠️ Optional parameter - no vault lookup
): Promise<EmbeddingService> {
    const capabilities = await detectDeviceCapabilities();
    const provider = selectEmbeddingProvider(capabilities, !!apiKey);  // Falls back to local if no apiKey

    const service = new EmbeddingService({
        provider,
        apiKey,  // Undefined if not passed!
        localModel: 'Xenova/all-MiniLM-L6-v2',
        batchSize: 32,
    });

    await service.initialize();
    return service;
}
```

**Impact**: Cloud embedding (required for Gemini-powered RAG) not enabled even when user has API key

**Root Cause**: 
1. No code retrieves API key from credential vault
2. API key parameter is optional (not enforced)

**Fix Required**:
- Call `credentialVault.getCredential('gemini')` before creating embedding service
- Pass retrieved API key to `createEmbeddingService()`
- Handle missing key gracefully with UI feedback
