## Implementation Steps

### Step 1: Create Plugin Directory Structure
- Create `src/plugins/monaco/` directory
- Create `index.ts`, `MonacoPlugin.tsx`, `useMonacoPlugin.ts`

### Step 2: Extract Monaco Logic
- Read current MonacoEditor component at `src/presentation/components/ide/MonacoEditor/MonacoEditor.tsx`
- Extract core editor logic into MonacoComponent
- Remove workspace-specific dependencies (useWorkspaceSync, workspace stores)
- Use ProjectContext.gateway for file I/O instead

### Step 3: Implement FeaturePlugin Interface
- Define monacoPlugin object in `src/plugins/monaco/index.ts`
- Set properties:
  - id: 'monaco'
  - name: 'Monaco Editor'
  - icon: <CodeIcon /> (or similar from lucide-react)
  - description: 'Code editor with multi-file support, auto-save, and syntax highlighting'
  - requirements: { storageType: 'any', deviceType: 'desktop', minWidth: 400, maxInstances: 1 }
  - MainComponent: MonacoComponent

### Step 4: Register Plugin in AppInitializer
- Add import: `import { monacoPlugin } from '@/plugins/monaco';`
- Add import: `import { registerPlugin } from '@/infrastructure/plugins/plugin-registry';`
- Call `registerPlugin(monacoPlugin)` in `initServices()` function
- Place AFTER FileTree registration (maintain order)

### Step 5: Migrate ide.$projectId Route
- Replace `ProjectProvider` import with `ProjectContextProvider`
- Import Monaco plugin: `import { monacoPlugin } from '@/plugins/monaco';`
- Wrap IDELayout with MonacoPlugin.MainComponent
- Remove old ProjectProvider import (CRITICAL: Grep must return 0 matches)

### Step 6: Verification
- Run TypeScript check: `pnpm tsc --noEmit` (0 errors required)
- Run old import check: `grep -n "from '@/lib/workspace/ProjectContext'" src/routes/ide.\$projectId.tsx` (0 matches)
- Run new import check: `grep -n "from '@/infrastructure/context" src/routes/ide.\$projectId.tsx` (1 match)
- Manual test: Load FSA project, open and edit file
