## Task 1: Fix Test File TypeScript Errors (P1, 3-4 hours)

### Error Categories Identified:

#### 1. Implicit `any` Types in Test Mocks
```typescript
// PROBLEM
vi.mock('some-module', () => ({
  importOriginal: importOriginal  // Parameter 'importOriginal' implicitly has 'any' type
}));

// SOLUTION
import type { VitestUtils } from 'vitest';
const importOriginal: VitestUtils['importOriginal'] = ...
```

**Files Affected**:
- `src/hooks/__tests__/useCanvasDrop.test.ts`
- `src/hooks/__tests__/useResponsive.test.ts`

#### 2. Type Mismatches in Test Fixtures
```typescript
// PROBLEM
const dragItem = {
  type: 'string',  // Type 'string' is not assignable to type 'DragItem'
  sourceId: 'abc',
  data: { title: 'Test' }
};

// SOLUTION
import type { DragItem } from '@/types/canvas';
const dragItem: DragItem = {
  type: 'source-node',
  sourceId: 'abc',
  data: { title: 'Test' }
};
```

**Files Affected**:
- `src/hooks/__tests__/useCanvasDrop.test.ts`
- `src/components/rag/__tests__/citation-components.test.tsx`

#### 3. Missing Properties in Test Store Objects
```typescript
// PROBLEM
const mockStore = {
  activeProjectConversationIds: {},
  eventHistory: [],
  // Missing 40+ properties from CombinedConversationState
};

// SOLUTION
import type { CombinedConversationState } from '@/infrastructure/persistence/stores/conversation';
const mockStore: Partial<CombinedConversationState> = {
  activeProjectConversationIds: {},
  eventHistory: [],
  // Only mock properties used in test
};
```

**Files Affected**:
- `src/infrastructure/persistence/stores/conversation/__tests__/conversation-events-slice.test.ts`
- `src/infrastructure/persistence/stores/conversation/__tests__/conversation-metadata-slice.test.ts`

#### 4. Unused Variables (TS6133)
```typescript
// PROBLEM
const messageId = 'msg-1';  // Declared but its value is never read

// SOLUTION
// Either use the variable or prefix with underscore
const _messageId = 'msg-1';  // Intentionally unused
```

**Files Affected**:
- All test files with `error TS6133`
