## Technical Details

### Component Architecture
```
CitationCountBadge (56 lines)
  └─ Badge with count, variant (default/secondary)

CitationSidebar (180 lines)
  ├─ CitationSearch (search input with debounce)
  ├─ CitationFilterSection (FilterChip for sources)
  ├─ CitationList (virtualized list)
  │  └─ CitationItem (clickable, with onCitationClick)
  └─ EmptyState / LoadingState

citation-types.ts (156 lines)
  ├─ DisplayCitation (extends Citation + display fields)
  ├─ CitationFormatter (helper functions)
  └─ CitationSearchParams (filter state)
```

### Key Features
1. **Search with debounce** (300ms) to reduce re-renders
2. **Source filtering** via FilterChip component
3. **Click-to-navigate** via onCitationClick callback
4. **8-bit styling** with design tokens
5. **i18n support** for English and Vietnamese
