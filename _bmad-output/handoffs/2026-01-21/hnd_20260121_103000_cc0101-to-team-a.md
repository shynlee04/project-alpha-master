## 1. Context Summary

**Epic:** EPIC-CC-01: Fix Hooks Error (Phase 1)
**Story:** CC-01-01: Remove useLiveQuery hook
**Epic Context:**
Fix Notes workspace crash to unblock user journey. The Notes workspace is currently crashing with "Rendered fewer hooks than expected" error on both desktop and mobile.

**Problem:**
The `NotesWorkspaceDefault` component in `src/routes/notes.lazy.tsx` uses `useLiveQuery` hook conditionally, violating React's rules of hooks. This prevents all users from accessing Notes workspace.

**Analysis Source:**
- Deep Architectural Analysis: Part 1.2 (Route Analysis), Part 2.1 (Use Cases), Part 3.1 (Infrastructure Analysis)
- Reference ADR-034 D11: State Scoping (Dexie hooks best practices)
- Reference ADR-033 D1: Platform Detection

**Why This Story:**
This is the first story in EPIC-CC-01 and the highest priority task. Once this fix is complete:
- Users can access Notes workspace on desktop (project picker)
- Users can access Notes workspace on mobile (auto-load browser-mode)
- Subsequent stories CC-01-02 (custom hook) and CC-01-03 (testing) can proceed

```typescript
function NotesWorkspaceDefault() {
  const platform = getPlatformContract();
  const [project, setProject] = useState<Project | null>(null);

  // ❌ Hook called conditionally (violation of React rules)
  const fsaProjects = useLiveQuery(async () => {
    if (!platform.canAccessFSA) return [];
    const allProjects = await db.projects.toArray();

      (p) => p.storageType === 'fsa' && p.workspaceBindings?.notes === true
    );

  useEffect(() => {
    // ... more logic that uses fsaProjects
  }, [platform.canAccessFSA, fsaProjects]);
}
```

**Expected Fix Pattern:**
```typescript
// ✅ CORRECT APPROACH (implement in CC-01-02)
function NotesWorkspaceDefault() {
  const platform = getPlatformContract();

  // Desktop with FSA → show picker
  if (platform.canAccessFSA) {
    return <ProjectPickerDialog open={true} targetWorkspace="notes" />;
  }

  // Mobile → auto-load browser-mode
  // Custom hook will handle project loading
  const browserProject = useBrowserModeProject(); // To be implemented in CC-01-02

  if (!browserProject) {
    return <LoadingSpinner />;
  }

  return (
    <ProjectProvider project={browserProject} workspace="notes">
      <NotesPage />
    </ProjectProvider>
  );
}
```

**Changes Required:**

2. Remove `fsaProjects` state variable
3. Remove `showPicker` state variable (not needed with direct return)

5. Simplify component logic to platform-based branching

**Warning:**
