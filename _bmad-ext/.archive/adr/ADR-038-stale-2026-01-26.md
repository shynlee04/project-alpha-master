# ADR-038: Event Listener Error Isolation

**Status**: PROPOSED
**Date**: 2026-01-18
**Author**: architect-ext

## Issue

The `cross-workspace-event-bus.ts` has **9 event listener registrations** without try-catch error handling. When any listener throws an error, it can crash the entire event bus, affecting all cross-workspace communication.

### Vulnerable Listeners

| Method | Lines | Issue |
|--------|-------|-------|
| `onSyncProgress` | 234-287 | No try-catch in emit |
| `onFileChange` | 288-341 | No try-catch in emit |
| `onWorkspaceChange` | 342-395 | No try-catch in emit |
| `onAgentStateChange` | 396-449 | No try-catch in emit |
| `onNoteUpdate` | 450-503 | No try-catch in emit |
| `onSearchComplete` | 504-517 | No try-catch in emit |
| `onSyncComplete` | 518-531 | No try-catch in emit |
| `onError` | 532-545 | No try-catch in emit |
| `onCustomEvent` | 546-561 | No try-catch in emit |

### Current Impact

- Throwing listeners can crash the event bus
- Cross-workspace communication fails silently
- No error recovery mechanism
- Event loop can be broken permanently

## Decision

Implement error isolation for all event listener registrations and emissions in the cross-workspace event bus.

### Proposed Solution

1. **Wrap all listener registrations** with try-catch in the emit chain
2. **Create error boundary pattern** for listener execution
3. **Add recovery mechanism** for crashed listeners
4. **Maintain audit trail** of listener errors

## Consequences

### Positive
- Event bus becomes resilient to throwing listeners
- Cross-workspace communication more reliable
- Errors are isolated and logged, not catastrophic
- Consistent with error handling patterns in codebase

### Negative
- Additional error handling code overhead
- Listener errors are swallowed (must be logged)
- Requires careful error type filtering

### Neutral
- No breaking changes to event bus API
- Performance impact negligible

## Implementation

### Step 1: Create event bus error isolation wrapper

```typescript
// src/infrastructure/events/event-bus-isolation.ts

import EventEmitter3 from 'eventemitter3';

export type EventBusErrorHandler = (error: Error, event: string, data?: unknown) => void;

export interface IsolatedEventBusOptions {
  onError?: EventBusErrorHandler;
  continueOnError?: boolean;
}

/**
 * Wraps EventEmitter3 with error isolation for listener protection.
 * Prevents a single throwing listener from crashing the entire bus.
 */
export class IsolatedEventBus {
  private emitter: EventEmitter3;
  private errorHandler: EventBusErrorHandler;
  private continueOnError: boolean;

  constructor(options: IsolatedEventBusOptions = {}) {
    this.emitter = new EventEmitter3();
    this.errorHandler = options.onError || this.defaultErrorHandler;
    this.continueOnError = options.continueOnError ?? true;
  }

  private defaultErrorHandler = (error: Error, event: string, data?: unknown): void => {
    console.error(`[EventBus] Listener error on "${event}":`, error);
    // Could emit to a dedicated error channel for monitoring
    this.emitter.emit('listener:error', { event, error, data });
  };

  /**
   * Emit with error isolation - wraps all listener calls in try-catch
   */
  emit(event: string, data?: unknown): boolean {
    const listeners = this.emitter.listeners(event);

    for (const listener of listeners) {
      try {
        listener(data);
      } catch (error) {
        this.errorHandler(error as Error, event, data);

        if (!this.continueOnError) {
          return false;
        }
      }
    }

    return true;
  }

  /**
   * Register listener with automatic error isolation
   */
  on(event: string, listener: (data?: unknown) => void): this {
    const isolatedListener = (data?: unknown) => {
      try {
        listener(data);
      } catch (error) {
        this.errorHandler(error as Error, event, data);
      }
    };

    this.emitter.on(event, isolatedListener);
    return this;
  }

  /**
   * Register one-time listener with error isolation
   */
  once(event: string, listener: (data?: unknown) => void): this {
    const wrappedListener = (data?: unknown) => {
      try {
        listener(data);
      } catch (error) {
        this.errorHandler(error as Error, event, data);
      }
    };

    this.emitter.once(event, wrappedListener);
    return this;
  }

  /**
   * Remove listener
   */
  off(event: string, listener?: (data?: unknown) => void): this {
    if (listener) {
      this.emitter.off(event, listener);
    } else {
      this.emitter.off(event);
    }
    return this;
  }

  /**
   * Get listeners for an event
   */
  listeners(event: string): Array<(data?: unknown) => void> {
    return this.emitter.listeners(event);
  }
}
```

import { IsolatedEventBus } from '../event-bus-isolation';

describe('IsolatedEventBus', () => {
  it('should continue emitting after throwing listener', () => {
    const bus = new IsolatedEventBus();
    const results: number[] = [];

    bus.on('event', () => { results.push(1); });

    bus.on('event', () => { results.push(3); });

    expect(results).toEqual([1, 3]); // Listener 2 threw, but 3 still executed
  });

  it('should call error handler when listener throws', () => {
    const errorHandler = vi.fn();
    const bus = new IsolatedEventBus({ onError: errorHandler });

    bus.on('event', () => { throw new Error('Test error'); });
    bus.emit('event');

    expect(errorHandler).toHaveBeenCalledTimes(1);
    expect(errorHandler).toHaveBeenCalledWith(
      expect.any(Error),

## Error Handling Strategy

### Error Classification

| Error Type | Handling |
|------------|----------|
| TypeError/NullPointer | Log and continue |
| Network/Async errors | Log and continue |
| Validation errors | Log and continue |
| Fatal errors (out of memory) | Stop bus, emit fatal event |

### Recovery Pattern

```typescript
// If a listener throws consistently, consider removing it
const errorCounts = new Map<string, number>();

this.on('event', (data) => {
  try {
    // Listener logic
  } catch (error) {
    const count = (errorCounts.get('event') || 0) + 1;
    errorCounts.set('event', count);

    if (count > 3) {
      // Remove problematic listener after 3 failures
      this.off('event', listener);
      console.warn(`[EventBus] Removed repeatedly failing listener for "event"`);
    }

    this.errorHandler(error as Error, 'event', data);
  }
});
```
