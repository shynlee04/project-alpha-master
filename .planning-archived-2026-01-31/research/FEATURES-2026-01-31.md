## Anti-Features

Features to explicitly NOT build. Common mistakes in this domain.

| Anti-Feature | Why Avoid | What to Do Instead |
|--------------|-----------|-------------------|
| **Full AI CRUD without approval** | Security risk, user trust | Suggest mode with diff view |
| **Server-side file storage** | Violates privacy promise | Local-first with optional sync |
| **Workspace as entity** | Conflates display with data | Project-centric with plugin views |
| **Same features for all devices** | Mobile can't run Monaco well | Capability-based plugin loading |
| **Glassmorphism UI** | Violates 8-bit design system | Sharp corners, pixel shadows |
| **Persisting UI state to Dexie** | Slow, causes sync issues | Zustand for UI, Dexie for data |
| **Direct plugin coupling** | Creates unmaintainable code | Event bus coordination |
| **Unlimited AI tool calls** | Runaway execution | Rate limiting, iteration caps |
| **Auto-sync on every keystroke** | Performance disaster | Debounced saves |
| **Safari 7-day workarounds** | Over-engineering | Document limitation, recommend Chrome |

### Critical Path Dependencies

1. **Project System** → Everything else (no project = no features)
2. **Storage Layer** → File operations, persistence
3. **Plugin System** → All plugin features
4. **Coordination Layer** → Cross-plugin features (live sync, etc.)
5. **AI System** → Chat, RAG, tool calling

## MVP Recommendation

For foundation reset, prioritize:

### Must Have (P0)
1. **Clean domain model** - No workspace confusion
2. **Single source of truth schemas** - One Project type, one FileMetadata type
3. **State layer boundaries** - Zustand vs Dexie clarity
4. **Plugin coordination** - Event bus, shared state
5. **Storage strategy** - Clear FSA vs IndexedDB decision flow

### Should Have (P1)
1. **Live editor sync** - Monaco ↔ Notes coordination
2. **AI suggest mode** - Diff view for proposed changes
3. **Platform capability detection** - Right plugins for right device
4. **Write lock protocol** - Concurrent editor safety

### Nice to Have (P2)
1. **Client-side RAG** - Embedding and search
2. **AI tool permissions** - Granular control
3. **Offline service worker** - Full offline support
4. **Git integration** - isomorphic-git

### Defer to Post-MVP
- Knowledge workspace features (ADR-033)
- Study/flashcard features (ADR-033)
- Cloud sync
- Multi-project support
- Collaborative editing
